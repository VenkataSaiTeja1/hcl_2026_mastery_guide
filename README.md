# HCL 2026 Mastery Guide

A comprehensive, self-contained recruitment preparation platform for B.Tech final-year students (CSE, IT, CSM, CAI, CSD, AIML, ECE, EEE).

## Features
- **Overview**: Reported HCL online-test pattern with direct navigation links to each section and topic.
- **Question Bank**: 200 practice MCQs across Quantitative Aptitude, Logical Reasoning, Verbal Ability, and Technical sections with worked solutions and filtering.
- **Mock Test**: Timed 15-question sectional mock test matching the reported HCL format.
- **Coding Round**: 23 core coding problems with full Java and Python solutions and test cases.

## Getting Started Locally

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Deployment
Configured for instant deployment on [Vercel](https://vercel.com).
